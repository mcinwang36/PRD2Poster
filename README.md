# PRD 2 Poster 

> 人机协同，AI 提效，人工把控质量。  
> 从 PRD 文档到最终海报，分 5 步完成。

---

## 流程总览

```
PRD 文档
  └─① 信息提取 ──→ Poster YAML（初版）
      └─② 人工审核 ──→ Poster YAML Ready
          └─③ Prompt 审核 ──→ Prompt_海报生成 Ready
              └─④ 海报生成 ──→ 第一版海报（GPT Image 2）
                  └─⑤ 二次编辑 ──→ 最终海报 ✓
```

**关键产出**：Poster YAML Ready · Prompt_海报生成 Ready · 最终海报

---

## Step 1 · 信息提取

**工具**：任意支持长文本的 AI（Claude / GPT / Gemini / Qwen / Deepseek等均可）

**操作**：

1. 打开 `Prompt_PRD信息提取`
2. 将 PRD 文档内容粘贴到对话框
3. 运行，得到 **Poster YAML 初版**

**输入**：PRD 文档  
**输出**：Poster YAML（初版）

> Prompt 会自动完成：技术语言 → 业务语言 / 功能描述 → 用户价值 / 系统能力 → 客户收益

---

## Step 2 · YAML 审核与修改

**操作者**：人工

逐字段校验以下内容：

| 字段 | 检查要点 |
|---|---|
| `title` | 是否为营销标题？有无技术术语？ |
| `subtitle` | 是否体现 3 个核心价值？10～20 字？ |
| `capabilities` | 最多 3 个，有无字段/模块等技术词？ |
| `metrics` | 数据是否合理？无数据时占位指标是否恰当？ |
| `scene` | 是否为真实业务场景？ |
| `slogan` | 是否与 title 完全不同？ |

修改完成后标记为 **Poster YAML Ready** ✓

---

## Step 3 · Prompt 审核

**操作者**：人工

检查 `Prompt_海报生成` 文件：

- 素材优先级顺序是否正确（P1 YAML → P2 系统截图 → P3 流程图 → P4 风格模板）
- 版式规则与 `visual.ui_layout` 是否匹配
- 禁止元素清单是否完整（机器人、芯片、赛博朋克等）

确认无误后标记为 **Prompt Ready** ✓

---

## Step 4 · 海报生成

**工具**：**ChatGPT（GPT Image 2 模型）** ← 建议使用此模型，以达到效果

**操作**：

1. 新建对话，进入 ChatGPT 图像生成界面
2. 上传以下素材（按优先级）：
   - **必须**：Poster YAML Ready（文本粘贴）
   - **推荐**：系统 UI 截图（参考图2）
   - **可选**：业务流程图（参考图3）
   - **可选**：品牌 Logo（参考图4）
   - **可选**：海报风格模板（参考图1，仅学习排版，不复制文字）
3. 粘贴 `Prompt_海报生成` 全文
4. 在 Prompt 末尾附上完整 Poster YAML 内容
5. 发送，等待生成

**输出**：第一版海报

> 如果对第一版不满意，可在同一对话中追加描述继续生成（SOP 中标注的「可再生成」路径）。

---

## Step 5 · 二次编辑与润色

**工具**：ChatGPT 界面内编辑 / 设计工具（Figma 等）

**操作**：

- 在编辑界面调整颜色、字体大小、元素位置
- 持续打磨细节直到满意
- 导出为最终交付格式

**输出**：最终海报 ✓

## 常见问题

**Q：Step 1 可以用 Claude 吗？**  
可以，信息提取不限模型，任何支持长文本输入的 AI 均可。

**Q：为什么海报生成推荐用 GPT Image 2？**  
GPT Image 2 支持在图像生成中融合多张参考图并进行精准的文字排版，是目前最适合此工作流的模型。

**Q：没有系统截图怎么办？**  
参考图 2 为可选素材，缺少时 AI 会根据 `system_name` 和 `page_name` 字段推断界面结构，但效果会有所下降。建议尽量提供。

**Q：YAML 里没有明确数据指标怎么办？**  
Prompt_PRD信息提取 会自动生成合理的占位指标（如 `100% 全流程覆盖` / `24h 处理时效`），在 Step 2 人工审核时确认是否符合实际即可。

**Q：第一版海报不理想，如何迭代？**  
在 ChatGPT 同一对话中追加修改描述，无需重新上传素材。如多次迭代后仍不满意，可回到 Step 2 调整 YAML 内容后重新生成。
